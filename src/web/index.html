BCP‑47 codes, comma separated, telling speech recognition which languages to expect. Empty means it guesses from the audio alone, which on a one-word reply has mis-read Russian as Spanish — the robot then answers in Spanish, because that is what it was handed. Hints, not a restriction.

POSIX TZ string, which counts west as positive, so a zone ahead of UTC gets a minus. This browser reports UTC, which is UTC0 — that is what the button fills in, derived from the offsets the browser gives for the current year. Only affects when the memory files roll over to a new day.

Nothing else sets the clock. Leave empty to disable, and memory files stay named undated.

Mic gain and noise filter apply immediately on Save. VAD settings apply to the next Gemini session, so end the current conversation and start a new one — no reboot needed. Speaker volume, model, voice, grounding, transcription language hints and the enable switches need a reboot. Timezone and NTP server are read once during startup, so they too apply on the next boot — and only affect how memory files are named. “Save and reboot” writes settings to SD first, then reboots the robot.

Secrets
Each line defines one network completely. Up to 8. Networks not named here are left alone; naming one with an empty password removes it.
The API never returns secret values, only set/missing status.

    
Web security
If no Web password is set, the local UI is open. After setting one, browser/API access uses HTTP Basic auth with user stackchan.
Stored on SD as SHA-256, not returned by the API.

    
Additional prompts
This is an SD/Web overlay appended to the base StackChan firmware instructions. The base prompt with camera, search, head, and safety rules is not shown or replaced here. Changes apply to the next Gemini Live session/connection.

    
Memory
Summary v2 calls Gemini Flash/Lite using the SD API key. Ordinary numbers/dates/model IDs are preserved exactly; private PIN/code/password/address values remain markers and private-memory only.
